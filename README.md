# Справочник пользователей

Учебное веб-приложение на Flask и SQLite с регистрацией, входом и общим справочником пользователей. Код основан на примерах официального учебника Flask; пример блога адаптирован под справочник.

## Возможности

- Регистрация, вход и выход.
- Общий справочник: добавление, просмотр, поиск, изменение и удаление записей.
- Сохранение данных в SQLite, хеширование паролей и CSRF-защита форм.

## Запуск

Требуется Python 3.10 или новее. Скачай репозиторий через **Code → Download ZIP** и распакуй либо клонируй его:

```bash
git clone https://github.com/Sneck24/-.git flask-site
cd flask-site
```

Из корневой папки проекта:

```bash
python -m venv .venv
```

В Windows PowerShell:

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

В Linux или macOS:

```bash
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python app.py
```

Открой http://127.0.0.1:8000/auth/register, создай аккаунт и войди.

## Структура

| Путь | Назначение |
| --- | --- |
| app.py | Точка запуска |
| flaskr/ | Обработчики Flask, доступ к SQLite, SQL-схема |
| flaskr/templates/ | HTML-страницы |
| flaskr/static/ | CSS |
| data/users.db | База данных с исходными записями справочника |

Таблица `user` хранит аккаунты и хеши паролей, `users` — записи справочника. Таблица аккаунтов создаётся при первом запуске. Все вошедшие пользователи имеют равные права на общий справочник.

В репозитории находится исходная база с тремя демонстрационными записями. Созданные на твоём компьютере аккаунты и изменения хранятся в локальной копии `data/users.db`. Файл `data/secret.key` создаётся автоматически и исключён из Git.

## Устройство приложения

HTML-формы отправляют запросы в Flask. Обработчики проверяют поля, выполняют параметризованные SQL-запросы через `sqlite3` и возвращают HTML-страницы. Пароли сохраняются в виде хешей. Это три логических уровня: представление, логика приложения и данные.

GitHub хранит исходный код. Для открытия сайта нужно запустить `app.py`; публикация репозитория сама по себе не запускает Flask-сервер.

Основа: [Flask Tutorial](https://flask.palletsprojects.com/en/stable/tutorial/), [Flask-WTF](https://flask-wtf.readthedocs.io/en/1.2.x/csrf/). Лицензия исходных примеров — в LICENSE-Flask.txt.
